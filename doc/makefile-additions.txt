## Makefile entries for Orange Pi 4 Pro / Allwinner A733 (sun60iw2)
## These entries must be added to the relevant Kconfig and Makefile locations
## in the Linux kernel source tree. Listed by subsystem.

================================================================================
1. arch/arm64/configs/orangepi_4pro_defconfig
================================================================================

  Simply place the defconfig file at:
    arch/arm64/configs/orangepi_4pro_defconfig

  No Makefile change needed; Kbuild picks it up automatically.

================================================================================
2. Device Tree
================================================================================

  Add DT source:
    arch/arm64/boot/dts/allwinner/sun60i-a733-orangepi-4-pro.dts

  If a shared dtsi exists, reference it:
    arch/arm64/boot/dts/allwinner/sun60i-a733.dtsi

  No Makefile change needed; allwinner DTs are built via the wildcard rule
  in arch/arm64/boot/dts/allwinner/Makefile (typically):
    dtb-$(CONFIG_ARCH_SUNXI) += sun60i-a733-orangepi-4-pro.dtb

  If the board is not in the wildcard, add explicitly:
    dtb-$(CONFIG_ARCH_SUNXI) += sun60i-a733-orangepi-4-pro.dtb

5. MMC (SD / eMMC)
================================================================================

  drivers/mmc/host/Makefile:

    # Allwinner sun60iw2 MMC host controller
    obj-$(CONFIG_MMC_SUNXI) += sunxi-mmc-new.o

  Note: CONFIG_MMC_SUNXI is a generic Kconfig symbol shared across Allwinner
  SoCs. The driver source (sunxi-mmc.c / sunxi-mmc-new.c) handles multiple
  SoC variants via of_device_id matching. No extra Makefile entry is needed
  beyond CONFIG_MMC_SUNXI=y in the defconfig.

23. NPU (Neural Processing Unit)
================================================================================

  drivers/misc/Makefile (or drivers/npu/Makefile if a dedicated subdir exists):

    obj-$(CONFIG_AW_NPU) += aw-npu.o

  Note: The NPU driver may be out-of-tree. If so, place the source at:
    drivers/misc/aw-npu.c
  or
    drivers/npu/aw-npu.c
  and add the obj- line above to the corresponding Makefile.

  Add Kconfig entry in drivers/misc/Kconfig (or drivers/npu/Kconfig):

    config AW_NPU
        bool "Allwinner NPU support"
        default y
        help
          Enable support for the Allwinner Neural Processing Unit
          found on the sun60iw2 (A733) SoC.

NOTES
================================================================================

  - Each CONFIG_ symbol above must correspond to an entry in the
    appropriate Kconfig file (usually in the same directory as the Makefile).

  - The defconfig file goes to:
      arch/arm64/configs/orangepi_4pro_defconfig

  - The boot script is compiled with mkimage before use:
      mkimage -C none -A arm64 -T script -d boot.cmd boot.scr

  - Device tree blob path (as referenced in boot.cmd):
      /boot/dtb/allwinner/sun60i-a733-orangepi-4-pro.dtb

  - Some symbols (e.g. MMC_SUNXI, STMMAC_ETH, DWMAC_SUN8I) are shared
    across multiple Allwinner SoCs. The sun60iw2-specific behavior is
    selected at runtime via of_device_id matching in the driver source.

  - Out-of-tree drivers (NPU, AIC8800 WiFi, ES8389 codec, etc.) need
    their source code placed in the appropriate kernel source directory
    or built as external modules.

  - Makefile lines marked with =o or =m produce loadable modules.
    Use =y for built-in drivers required at early boot (eMMC, console,
    root filesystem support, display output).
